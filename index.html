Digital Tool Crib & Field Kit Auditor

Kit audits that work when there's no signal.

Offline-first inventory auditing for field techs, diesel fitters, and drilling crews — trucks, kits, and consumables tracked whether or not there's reception, with everything reconciling cleanly once the crew is back in range.

Live preview — seeded with demo data, still in active development
Open the preview ↗ Get in touch
How it's built

An event log, not a spreadsheet

Every count, pack-out, and restock is an append-only event — so two techs auditing the same kit offline, syncing hours apart, never silently overwrite each other.

📶

Offline-first, always

A React PWA backed by IndexedDB — full functionality with zero signal, syncing to Supabase whenever a connection reappears.

✅

Pack-out audits

Mandatory-missing items hard-block departure; low-stock consumables soft-warn instead — so real problems never get lost in noise.

📋

Restock manifests

Generated straight from the same event log as the audits — no separate system to keep in sync, exportable as PDF or CSV.

🔁

Idempotent sync

Events replay safely no matter the order they arrive in; last-write-wins only where it's actually safe — locations, assets, kit metadata.

🪪

Shared-device friendly

A lightweight "chip tap" switch-user for trucks and tablets passed between techs — no login wall for the day-to-day.

🎒

Built for the field, not an office

High-contrast, outdoor-readable UI aimed at techs checking a kit in direct sun, not a warehouse desk.
